# User Story: Dashboard Geoespacial Interativo com Minimapas Oficiais

**As a** analista de esports, treinador ou fã de VALORANT,
**I want to** explorar os mapas competitivos em uma interface web interativa, alternando suavemente entre densidades de abates, mortes e vantagens de vitória por posicionamento (winrate Bayesiano),
**so that** eu possa tomar decisões táticas embasadas em dados estatisticamente confiáveis de cada fase do round.

<objective>
Construir o renderizador visual geoespacial em Plotly com integração às imagens oficiais de minimapas locais e a aplicação web completa em Streamlit (`app.py`), com navegação por Tiers de mapas, destaque para Ascent, Lotus e Haven, filtros temporais e métricas consolidadas.
</objective>

  <name>Módulo de renderização geoespacial em Plotly (src/visualization/map_renderer.py)</name>
  <files>src/visualization/map_renderer.py, src/visualization/__init__.py, tests/test_visualization.py</files>
  <action>
    Implementar o renderizador de mapas em `src/visualization/map_renderer.py`:
    1. Função `get_minimap_image_path(map_name: str) -> Optional[Path]`: localiza a imagem PNG correspondente em `assets/maps/<map_name.lower()>.png`.
    2. Função `create_spatial_figure(matrix, mode, map_name, points_df=None, show_points=False)`:
       - Configura o canvas com layout proporcional 1:1, eixos $[0.0, 1.0]$ com $Y$ invertido para alinhar perfeitamente à imagem.
       - Adiciona a imagem local como layout image (`xref="x", yref="y", x=0, y=0, sizex=1, sizey=1, layer="below"`).
       - Renderiza a superfície de acordo com o modo:
         - **Abates (Kills):** `colorscale="Hot"` ou `"YlOrRd"` com opacidade calibrada (0.6 a 0.75).
         - **Mortes (Deaths):** `colorscale="Inferno"` ou `"Reds"` com opacidade calibrada.
         - **Vantagem (Winrate Bayesiano):** `colorscale="RdBu_r"` ou `"Spectral"`, intervalo zmin=0.3, zmax=0.7 (centrado em 0.5), onde azul/verde indica vantagem posicional e vermelho desvantagem.
       - Se `show_points=True` e `points_df` for fornecido, adiciona camada de dispersão de pontos (`go.Scatter`) com hover rico (round, tempo, arma, time vencedor).
    3. Em `tests/test_visualization.py`, testar a criação de figuras para cada modo e mapa, validando existência dos elementos de layout e tipos Plotly.
  </action>

  </verify>
